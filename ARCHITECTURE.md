# Architecture

The bot is a LiveKit Agents worker running a classic voice pipeline: Deepgram Nova 3 turns the clinic agent's speech into text, gpt 4o mini decides what the patient says next, and Cartesia Sonic 2 speaks it, with Silero voice activity detection and LiveKit's turn detector deciding when it's the patient's turn. I chose a pipeline over a speech to speech model because every stage is inspectable and tunable on its own, which matters when the whole point is to judge someone else's agent. I can see exactly what the bot heard, boost recognition of doctor names with Deepgram keyterms, and tell whether a bad moment came from my side or theirs. `run.py` places each call by creating a LiveKit room, dispatching the agent into it, and dialing the clinic through a Twilio Elastic SIP trunk. Each scenario is a small JSON file (context, goal, twist) layered on a shared patient persona and turned into the bot's instructions, so adding a test means adding a file, not writing code.

Most of the engineering went into making calls behave like real calls. The bot stays quiet when the clinic says "one moment" by cancelling its reply when the clinic's last sentence is a hold phrase instead of a question. An `end_call` tool lets the bot hang up on its own but refuses before 60 seconds, and a timer nudges it to wrap up at 2:20 and hangs up at 3:05 so every call stays under three minutes. A hidden recorder participant subscribes to both audio tracks, mixes them on one shared clock, and stamps each transcript line with the moment that speech started, so any timestamp in a transcript lines up with the recording. `run.py` watches the room and deletes it the moment the clinic hangs up, which ends the job and triggers the recorder to write the OGG file with ffmpeg. The main tradeoff is that scenarios run in order against shared demo data, so later calls see what earlier calls changed. That made the tests more realistic and is how the duplicate patient record bug surfaced, but it also means a scenario's written context can go stale, which is why the cancel scenario was rewritten to not assume a specific date.
